模板怎么写

                
模板由两部分组成：HTML 决定结构，必须包在 <style>...</style> 中的 CSS 决定外观。CSS 不能直接写在最外层；支持普通标签、SVG 和内嵌样式，保存后立即生效。

                

                    
只改自己的时钟：每条样式都用 .bpx-player-top-clock 开头，避免影响 B 站页面。

                    
最常见的失效原因：把 CSS 漏在 <style>...</style> 外面。请先写 <style>，最后写 </style>，再放 HTML 标签。

                    
不需要写 JavaScript：<script> 不会执行；图片和外部字体可能发出网络请求。

                


                
占位符

                

                    
{{hh}}当前小时（两位，24 小时制）

                    
{{mm}}当前分钟（两位）

                    
{{ss}}当前秒（两位）

                    
{{time}}完整 HH:MM:SS

                


                
可复制的模板


                

                    起步模板：彩色时间卡片展开代码
                    

                        
                    
<style>
.bpx-player-top-clock .my-clock {
  font-family: ui-monospace, monospace;
  font-size: 30px;
  color: #fff;
  background: #fb7299;
  border-radius: 8px;
  padding: 4px 14px;
}
</style>
<div class="my-clock">{{time}}</div>
