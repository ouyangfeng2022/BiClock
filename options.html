自定义 HTML 模板

启用后，扩展不再每秒重建时钟子树——你写的 HTML 直接作为时钟内容，里面的装饰元素（小狗、图标、容器）都会保留。时间用占位符 {{hh}} {{mm}} {{ss}} {{time}} 表示，每秒只更新占位符的文本，不会清空其它内容。外观由模板里的内联 style 或 <style> 自理，无需 !important。位置仍由预览拖拽控制。

启用

HTML 模板说明

模板里写任意 HTML 结构，扩展把 {{hh}} / {{mm}} / {{ss}} / {{time}} 替换成当前时/分/秒/完整时间，每秒只更新占位符，模板里的其它元素原样保留。同一占位符可多次出现。未识别的 {{...}} 原样当文本保留。

注意：模板里的 <script> 不会执行（浏览器对 template 内容的内置行为）；<img> 等会真的发起网络请求，请自行负责。外观请在模板内用内联 style 或 <style> 自理。

占位符

{{hh}}当前小时（两位，24 小时制）
{{mm}}当前分钟（两位）
{{ss}}当前秒（两位）
{{time}}完整 HH:MM:SS

点击「复制」可直接粘贴到上面的输入框试用。复制后记得勾「启用」。

关于

BiClock 是一个轻量的 Manifest V3 浏览器扩展，在 Bilibili 视频播放器顶部叠加显示当前时间。纯原生 JS，零依赖、零构建，同一套代码同时支持 Chrome / Edge / Firefox。
