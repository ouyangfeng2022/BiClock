使用说明

支持标签、SVG 和 <style>；保存后立即生效。

建议以 .bpx-player-top-clock 作为样式选择器前缀。

<script> 不会执行；图片和外部字体可能发出网络请求。

占位符

{{hh}}当前小时（两位，24 小时制）
{{mm}}当前分钟（两位）
{{ss}}当前秒（两位）
{{time}}完整 HH:MM:SS

示例

最简卡片展开代码 
<style>
.bpx-player-top-clock .my-clock {
  font-family: ui-monospace, monospace;
  font-size: 30px;
  color: #fff;
  background: #fb7299;
  border-radius: 8px;
  padding: 4px 14px;
}
</style>
<div class="my-clock">{{time}}</div>

关于

BiClock 是一个轻量的 Manifest V3 浏览器扩展，在 Bilibili 视频播放器顶部叠加显示当前时间。纯原生 JS，零依赖、零构建，同一套代码同时支持 Chrome / Edge / Firefox。
